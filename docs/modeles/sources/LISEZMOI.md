# Sources PlantUML des modèles

Un fichier `.puml` par diagramme, extrait de `../diagrammes.md` (qui contient aussi les
explications). Pour produire un export lisible (SVG ou PNG) :

* VS Code : extension « PlantUML », puis « Export Current Diagram » ;
* ou en ligne de commande : `plantuml -tsvg *.puml` (Java + PlantUML installés) ;
* ou en collant le contenu sur https://www.plantuml.com/plantuml.

Placer les exports dans `../exports/` et les mettre à jour à chaque modification d'un modèle.
