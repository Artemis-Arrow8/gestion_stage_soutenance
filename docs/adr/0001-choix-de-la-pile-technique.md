# ADR 0001 : Choix de la Pile Technique

**Projet :** SGSUS  
**Auteur :** Kadiatou Helene GUINDO (Lot 1)  
**Date :** 23 Octobre 2026  
**Statut :** Accepte  

---

## 1. Contexte
Il faut definir une pile technique robuste pour developper rapidement le backend, gerer des donnees relationnelles complexes et proposer une application multiplateforme.

## 2. Options Etudiees
- **Option 1 :** Node.js + React Native + MongoDB.
- **Option 2 :** Django REST Framework + PostgreSQL 17 + Flutter (Retenue).

## 3. Decision Prise
L'equipe valide l'**Option 2** (Django + PostgreSQL + Flutter). PostgreSQL apporte la puissance necessaire pour les contraintes de planning et Django assure une securite native elevee.
